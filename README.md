# Claude Code 開発環境テンプレート

Claude Code で、新規開発と既存改修の両方に対応するための汎用テンプレートです。
開発フェーズ別スキル、専門サブエージェント、詳細規約、フック、スラッシュコマンドで構成されます。

詳しい使い方（開発の進め方・日常操作・フックの動作・FAQ）は [MANUAL.md](MANUAL.md) を参照してください。
