# 作業ログの運用

<!-- このファイルは運用の定義。実際のログは Claude がセッションごとに追記する -->

セッション単位の要約ログを保存するディレクトリ。ユーザーが `/handover`「ログを記録して」
「ログに残して」と依頼したときのみ、Claude がそれまでの作業の要約
（依頼・相談の内容 → 実施内容・結果）を追記する。自動では追記しない。

## ファイル規則
- 1セッション = 1ファイル。ファイル名は `YYYY-MM-DD_HHMMSS.md`
- 採番はセッション内で最初に記録した時点の日時。同じセッション中の2回目以降の
  「ログを記録して」は同じファイルへ追記を続ける
- git 管理外（.gitignore 登録済み）。運用定義の README.md（本ファイル）のみ管理する

## 書式

```markdown
# セッションログ YYYY-MM-DD HH:MM

- HH:MM <依頼・相談の内容> → <実施内容・結果>
- HH:MM <依頼・相談の内容> → <実施内容・結果>
```

- 1エントリ = 1回の記録。前回の記録以降の「何を頼まれ、何をして、どうなったか」を1〜3行に要約する
- セッション中に合意した決定・保留はエントリ内に含める（例: 「〜で合意」「〜は保留」）
- 相談・質問だけのターンも1行残す（後から経緯を追うときに効く）

## 追記の原則
- 末尾への追記のみ。既存エントリの書き換え・削除はしない（時系列の経緯を保つ）
- 会話の転記はしない（要約のみ）。会話全文などの完全な記録が必要な場合は、
  Claude Code 本体が保存する `~/.claude/projects/<プロジェクト>/<セッションID>.jsonl` を正とする

## 参照規則
- 過去ログの読み込みは自動では行われない。ユーザーの依頼（`/read-handover`「経緯を確認して」「ログを読んで」等）を受けて、ファイル名（開始日時）の新しいものから必要な分だけ読む
